# Learning Journey

Before starting this room, I had limited experience with PCAP analysis and investigating network traffic using Wireshark.

During this challenge, I learned:

- How to use Wireshark display filters.
- How to analyze HTTP GET requests.
- How to inspect HTTP streams.
- How to extract and analyze HTTP cookies.
- How XOR encryption works.
- How Base64 encoding and decoding work.
- How to use CyberChef for data decryption.

This room helped me improve my practical network traffic analysis and cybersecurity investigation skills.
